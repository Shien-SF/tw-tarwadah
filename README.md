# ملمح — Malmah

مجموعة سلة تضم تسعة عناصر مستقلة لعرض المنتجات داخل الثيم. لا تتضمن صفحة هبوط أو هيدرًا أو فوترًا.

## تشغيل المعاينة

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd run dev
```

افتح `http://127.0.0.1:5173/` لقائمة العناصر. كل بطاقة تفتح عنصرًا واحدًا. يدعم الرابط `lang=ar` أو `lang=en`. المحرر الرسمي متاح في `/editor.html`. قوالب الهبوط القديمة غير متاحة في هذه النسخة.

المعرّفات البرمجية `tarwadah-*` ومفاتيح العناصر محفوظة حتى لا تفقد إعدادات العناصر السابقة عند تحديث المجموعة. الاسم الظاهر للتاجر هو «ملمح».

## ملفات التقديم والمساعدة

- [دليل التاجر بالصور](docs/merchant-guide.html)، و[نسخة Markdown](docs/merchant-guide.md).
- [نصوص التقديم وعناوين الصور وأوصافها باللغتين](docs/listing-copy.md).
- صور العناصر التسعة في `docs/screenshots/`؛ لقطات المصدر في `docs/screenshots/raw/`.
- [خطوات إعادة التقديم وما يلزم يدويًا](docs/SALLA-SUBMISSION.md).
- `artifacts/salla-submission/`: مجلد جاهز للرفع اليدوي، يحوي الدليل والصور وخريطة الروابط.

نسخة القوالب الثلاثة القديمة محفوظة على سطح المكتب باسم `Tarwadah-Templates-Backup-20261107-143407`، وتشمل الكود والإعدادات والصور المحلية وتعليمات التشغيل. لا تعِد نسخ `templates` إلى نسخة التقديم الحالية.

## البناء والتحقق

```powershell
pnpm.cmd run check
pnpm.cmd run build
pnpm.cmd run check:preview
pnpm.cmd run check:release
```

`check:preview` يحتاج تشغيل خادم التطوير. فحص المحتوى في `check:release` يفشل عمدًا ما دامت الصور المحلية لم تُرفع إلى HTTPS. نجاح البناء لا يثبت نجاح الشراء على متجر سلة.

ملف `twilight-bundle.json` هو مصدر إعدادات العناصر وقيمها الافتراضية. بعد تعديل قيمه شغّل `pnpm.cmd run sync:defaults` لتحديث `src/shared/defaults.json`. الاسم القديم لأمر المزامنة محفوظ للتوافق، لكنه لم يعد يعتمد على أي قالب.

`dist/` جزء من Git لأن إصدار Twilight يقرأ ملفات البناء من الكوميت. يجب إرفاق كل ملفات البناء المشتركة والعناصر التسعة عند رفع الإصدار، ثم فحصه بـ `pnpm.cmd run check:dist` بعد إنشاء الكوميت. لم يتم إنشاء كوميت أو رفع هذه التعديلات تلقائيًا.

## إعادة توليد الدليل والصور

```powershell
pnpm.cmd run docs:build
playwright-cli -s=malmah open http://127.0.0.1:5173/
playwright-cli -s=malmah run-code --filename=scripts/capture-components.cjs
playwright-cli -s=malmah run-code --filename=scripts/capture-boards.cjs
pnpm.cmd run prepare:submission
```

راجع نتيجة فحص المتصفح: `failures` و`errors` يجب أن يكونا فارغين. التصوير يستخدم محتوى تجريبيًا وروابط نموذجية للمقدمة والشريط لإظهار حالة ضبط الزر؛ هذه الروابط غير محفوظة في قيم الإنتاج. لقطات تقليل الحركة تبيّن التصميم الساكن؛ اختبر الحركة كذلك في المتجر.

بعد رفع مجلد التقديم إلى استضافة HTTPS، حدّث الروابط بهذا الأمر مع رابط المجلد الحقيقي:

```powershell
node scripts/prepare-media.mjs --base-url=https://YOUR-HOST/PATH/
pnpm.cmd run check:release
```

الأمر يتحقق من وصول الصور ونوع محتواها قبل تعديل أي رابط، ويحدّث القيم الافتراضية تلقائيًا. يحتفظ `public/demo-uploads/` بصور المعاينة المحلية فقط، ولا يدخل ضمن `dist/`.

## المنتج والشراء

كل عنصر يختار منتجه بنفسه. عند استخدام الشريط وبطاقة الشراء لنفس المنتج، اختر نفس المنتج في إعدادات كل عنصر. بطاقة الشراء تستخدم عناصر سلة الأصلية للخيارات والكمية والإضافة إلى السلة. بدون اختيار منتج حقيقي تُعرض حالة معاينة؛ لا يُفعّل شراء حقيقي على المتجر.

المقدمة والشريط يدعمان رابطًا مستقلاً إذا لم يوجد القسم المستهدف. شريط المنتج يستخدم رابط المنتج الحقيقي من سلة كبديل إضافي. لا تظهر روابط إجراء بلا وجهة صالحة. العناصر تحافظ على مؤشر وتمرير الثيم ولا تفرض مؤشرًا أو تنعيم تمرير عامًا.
